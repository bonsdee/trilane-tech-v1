# Trilane Tech logo (v2)

The mark is a "T" made of three separate pieces, one for each person in the pod. The two top bars are the website side and the operations side, and the stem holds them up. Together they make one letter: three specialists, one team.

Version 2 changes the name to all caps in a wide, geometric typeface and adds a set of logos with the tagline **THINK FORWARD. BUILD SMARTER**.

## Files

| File | Use it for |
|---|---|
| `svg/logo-horizontal-*.svg` | The main logo: website header, email signature, documents |
| `svg/logo-horizontal-tagline-*.svg` | The main logo with the tagline: proposals, decks, website footer, banners |
| `svg/logo-stacked-*.svg` | Square-ish spaces: business cards, social headers, signage |
| `svg/logo-stacked-tagline-*.svg` | The stacked logo with the tagline: posters, cover pages, event backdrops |
| `svg/mark-*.svg` | The T on its own, where the name already appears nearby |
| `svg/app-icon.svg`, `png/app-icon-*.png` | Social media avatars, Google Business profile, app icons |
| `svg/favicon.svg`, `favicon.ico`, `png/favicon-32.png` | Browser tab icon |
| `png/apple-touch-icon.png` | iPhone home-screen icon (180 × 180) |
| `fonts/` | The typeface files, to use on the website and in documents |

Each logo comes in four versions: `light` (for white or light backgrounds), `dark` (for dark backgrounds), `black` and `white` (one colour, for printing, embossing and photos).

Use the SVG files wherever they're accepted, because they stay sharp at any size. The PNGs have transparent backgrounds, so the dark and white versions look empty when you open them on white. That's expected.

## Typeface

The logo uses **Orbitron**: Bold for "TRILANE", Regular for "TECH" and Medium for the tagline. It stands in for HK Modular, a paid font from Hanken Design Co. with a similar wide, modular shape. Orbitron is free under the SIL Open Font License, including for commercial use, and the licence is in `fonts/OFL.txt`.

The letters in the logo files are already converted to shapes, so they look right on any computer, with or without the font installed. If you buy HK Modular later, the logo can be rebuilt with it in a few minutes.

For body text on the website and in documents, keep using Inter. Orbitron is a display face, so use it only for the logo, headings and short labels.

## Rules

- **Clear space:** keep empty space around the logo at least as wide as the stem.
- **Minimum size:** 24 px tall on screens and 8 mm tall in print for the horizontal logo. With the tagline, 40 px and 12 mm, so the tagline stays readable. Below that, use the version without the tagline, or the mark on its own.
- **Don't:** recolour the pieces outside the palette above, stretch or rotate the logo, close the gaps between the three pieces, add shadows or outlines, or set the name in another font.
